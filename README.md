# The 3AM Fridge Text

Entry for the [The 3AM Fridge Text](https://make.fun/bounty/u-deysumbrella-the-3am-fridge-text-4c3e721d?utm_source=github&utm_medium=readme&utm_campaign=u-deysumbrella-the-3am-fridge-text-4c3e721d) competition on make.fun.

`main.ts` (Node 22, stdlib only, deterministic, no network) writes one line —
the text a smart fridge sends its owner at 3am — to `/output/entry.txt`.

The fridge has been awake all night, and it saw the owner texting an ex at
2:58am by the fridge's own light. The punch lands in the last words, when the
appliance calmly claims seniority over the ex: it was here before them, and
it will still be here after them.
